Real TTS tests and model downloads

Every local model is downloaded only when you click its Download button. The sizes cover the exact selected model and voice data; official executable SDK/WASM code is already packaged with the extension. MediaPipe's one-file bundle includes its phonemizer and voices. ONNX has an experimental US-English dictionary-to-phoneme path for known words. The dictionary is a separate, optional verified download and is cached offline; it is not packaged with the extension. Arbitrary text and long-form reading remain unvalidated.

Kokoro-FastAPI — existing Docker/server

Runs only on the configured server, never when a local backend is selected. Testing sends the sample text to that server.

Not tested

Verify cached data checks the stored model bytes against pinned SHA-256 hashes. MediaPipe verification hashes the cached model in chunks without a second model-sized buffer. ONNX and dictionary verification use WebCrypto and can temporarily allocate one asset's bytes (up to about 92 MB). Corrupt cached assets are removed; replacements are never downloaded without another explicit Download click.
