Use the individual model tests below to verify real synthesis. MediaPipe and dictionary-ready ONNX q8 can measure the same English input, but may differ in voice and phonemization; IPA-only measurements must not be ranked against English-text results. A capability check alone does not establish inference or audio quality.

Voice mixing: Weighted FastAPI mixes (for example af_sarah(5)+af_nicole(3)) apply only to the server backend. MediaPipe accepts a single official voiceId per utterance. ONNX currently uses the installed single voice asset; style-vector blending is prepared in-repo for future multi-voice downloads and is not a multi-synthesis PCM mix. Server mixer preferences stay stored separately when you use a local backend.

Real TTS tests and model downloads

Every local model is downloaded only when you click its Download button. The sizes cover the exact selected model and voice data; official executable SDK/WASM code is already packaged with the extension. MediaPipe's one-file bundle includes its phonemizer and voices. ONNX has an experimental US-English dictionary-to-phoneme path for known words. The dictionary is a separate, optional verified download and is cached offline; it is not packaged with the extension. Arbitrary text and long-form reading remain unvalidated.

Kokoro-FastAPI — existing Docker/server

Runs only on the configured server, never when a local backend is selected. Testing sends the sample text to that server.

Not tested

Verify cached data checks the stored model bytes against pinned SHA-256 hashes. MediaPipe verification hashes the cached model in chunks without a second model-sized buffer. ONNX and dictionary verification use WebCrypto and can temporarily allocate one asset's bytes (up to about 92 MB). Corrupt cached assets are removed; replacements are never downloaded without another explicit Download click. A long integrity check can be cancelled with the Verify button; no replacement download starts automatically.

Measured local English results

Run at least two local English tests to compare their measured timings.

Backend / pathWarm p50Warm p95RTF p50

Only successful tests of the current shared English sample appear here. IPA-only ONNX and server/network tests are excluded. Values measure completed synthesis, not time to first audio. Voices and phonemization may differ; no automatic ranking or backend selection.

Measurements are taken from actual synthesized audio, not GPU adapter detection. Local figures are warm, after engine initialization; server timings exclude audio playback. ONNX q8 measures the same English input only after the optional dictionary has been installed and the entire sample is supported; otherwise it reports non-comparable IPA-only timings. ONNX q8f16 remains IPA-only. A passed IPA probe cannot enable ordinary English playback.
